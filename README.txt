QUOTEX SIGNAL WEB APP (85%-98% Accuracy)
----------------------------------------

📌 ABOUT
This is a high-accuracy Forex & Quotex signal web app.
It uses 1-minute and 5-minute candles with indicator-based confirmation.

⚙️ FEATURES
- Real-time signals (BUY / SELL / WAIT)
- Confidence % shown
- Indicators: SMA, MACD, RSI, Bollinger Bands, Momentum
- Multi-timeframe (1m + 5m) confirmation for 85%-98% accuracy
- FastAPI + Uvicorn server

🚀 DEPLOY ON RENDER
1️⃣ Go to https://render.com → New → Web Service  
2️⃣ Connect your GitHub repo or upload ZIP  
3️⃣ Make sure the folder has:
   - main.py
   - requirements.txt
   - render.yaml
   - README.txt
4️⃣ After deploy, go to "Environment" tab → Add Variable:
      Name: FINNHUB_API_KEY
      Value: your Finnhub API key
5️⃣ Click “Deploy”  
6️⃣ Wait until live URL appears → open in browser!

💻 LOCAL RUN (optional)
pip install -r requirements.txt
python main.py

Then open your browser at:
👉 http://127.0.0.1:8000

Enjoy accurate real-time Quotex signals ⚡
