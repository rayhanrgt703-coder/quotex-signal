# 💹 Smart Pro Signal v5.0 — Real-Time Sure Signal

A high-accuracy Quotex/Forex signal app using TwelveData API (1m candles).

### ⚙️ Setup
1. Create a Render Web Service.
2. Upload:
   - `main.py`
   - `requirements.txt`
   - `render.yaml`
3. Add your `TWELVE_DATA_API_KEY` in environment variables.
4. Deploy.

### 📊 Features
- Real-time 1-minute candle updates
- Candlestick + MA + RSI + Bollinger + MACD signals
- Confidence filter ≥ 90%
- Start/Stop button
- Previous 30 signals saved
- Auto-refresh every 30s
