# 💹 Smart Pro Signal v2.0 (Real-Time 1m Candle)

A high-accuracy Quotex/Forex signal app powered by Twelve Data API.  
It analyzes 1-minute candles using price action + candlestick patterns.

---

### 🔧 Setup (Render or Local)

1. Upload these files together:
   - `main.py`
   - `requirements.txt`
   - `render.yaml`
   - `README.md`

2. Create an account at [https://twelvedata.com](https://twelvedata.com)  
   Copy your API key from dashboard.

3. In **Render Dashboard → Environment → Add Environment Variable**
   - **Key:** `TWELVE_DATA_API_KEY`
   - **Value:** `your_api_key_here`

4. Deploy the app or restart it.

---

### 📊 Features
- Real-Time 1-Minute Candle Analysis  
- Candlestick Pattern Recognition (Hammer, Doji, Engulfing, etc.)  
- BUY/SELL Signal with Confidence %  
- Previous Signal History  
- Auto-refresh every 60 seconds  
- Works Free with [Twelve Data API](https://twelvedata.com)
